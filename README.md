## Publication de documents

Sur GitHub, ouvrez le dossier voulu puis **Add file → Upload files**, sélectionnez votre PDF (ou PPTX, DOCX, XLSX, R, PY, TEX, CSV, ZIP), puis **Commit changes** sur `main`.

- `programme/` : programme officiel et présentation du programme.
- `cours/` : polycopiés.
- `presentations/` : présentations Beamer/PDF des chapitres.
- `td/` : feuilles de TD.
- `corriges/` : corrigés.
- `tp/` : travaux pratiques et scripts.
- `applications/` : données et études appliquées aux quatre filières.
- `bibliographie/` : documents dont la redistribution est autorisée.

Les listes de fichiers des rubriques se construisent automatiquement par lecture de l'API publique GitHub ; si ce service est temporairement indisponible, un lien vers le dossier du dépôt est affiché.
